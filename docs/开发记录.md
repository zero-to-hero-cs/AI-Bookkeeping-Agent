## 一、改了什么（按严重程度排）

### main.py

| # | 原来的问题 | 后果 | 现在怎么做 |
|---|---|---|---|
| 1 | prompt 里只有 `record/ask/refuse`，**没有 `query`** | MVP 第 3 项「自然语言查账」完全没落地，"上个月交通花了多少"会被当成闲聊拒掉 | 加了 `query` 意图，识别出类别 + 时间词后写 `query.txt`（三行：类别 / 开始日期 / 结束日期）|
| 2 | `refuse` 落进了 `else` 分支，前面拼了 `❌ 系统出错：` | 越界拦截做对了但显示成"系统出错"，功能对、展示错 | 四种 action 各自独立处理，refuse 有独立文案 |
| 3 | `API_KEY = "YOURAPI"` 写死在源码里 | 队里 4 个人没 key 跑不了；一填上再 commit，**key 就进 GitHub 历史**（考核明确要查）| 源码里不写 key：界面菜单「5. 设置 API Key」→ 写进 `config.txt`（不进 Git）；也支持环境变量覆盖 |
| 4 | 空输入时直接 `exit()`，**不写 reply.txt** | UI 读到上一次的旧回复，用户以为记账成功了 | 所有退出路径都写 `reply.txt` |
| 5 | 路径全是 `"data/input.txt"` 相对路径 | 从别的目录启动会在别处建 `data/`，然后"记账成功但查账是 0" | 全部基于 `Path(__file__)` 的绝对路径 |
| 6 | 没设 `temperature`、没校验金额 | 同一个输入偶尔给出不同结构；模型可能返回 `"32元"` 或负数，写进账本后 C 算成 0 | `temperature: 0` + `normalize_amount()` / `normalize_category()` 入库前校验，不合法就转成追问 |
| 7 | 没有兜底 | 队友没 key、断网、欠费 → 整个程序不可用 | 加了 `local_parse()` 本地规则：**没 Key 也能跑全流程**（记账/查账/追问/拦截都有）|
| 8 | 追问没有记忆 | "买衣服"→追问→下一句"399"时模型看不到上下文，只能瞎猜 | `data/pending.json` 记住缺什么，**超过 10 分钟自动作废**（避免上次的追问残留影响下次） |
| 9 | `date` 字段拿到了却没用 | "昨天"记的账全变成今天，时间统计不可能对 | 模型只给"昨天"这种原话，**日期由 Python 换算**（不让模型算日期，它算日期错误率极高）|

### ui.py

| # | 原来的问题 | 后果 | 现在怎么做 |
|---|---|---|---|
| 1 | `os.system("calc.exe")` | **cmd 会先搜系统 PATH，弹出的是 Windows 自带计算器**。演示现场笑场，评审会认为不会用 subprocess | `subprocess.run([str(BASE_DIR/"calc.exe")], cwd=BASE_DIR)`，绝对路径 + 指定工作目录 + 超时 |
| 2 | `os.system("python main.py")` | 依赖 PATH 里的 python；失败时**完全静默**，你只看到"未收到 AI 回复"，查不出原因 | 改成 `[sys.executable, str(BASE_DIR/"main.py")]`，能拿到返回码和报错 |
| 3 | 调 main 前不删旧 reply.txt | main 崩溃时读到上一次的回复，**静默错误**（假成功） | 先删 `reply.txt` → 调 main → 检查文件是否存在，不存在就报"main.py 可能崩溃了 + 控制台输出" |
| 4 | 查账**只调 calc.exe**，不走 main.py | `query.txt` 没人写，"查交通"变成"查总账"，按分类查不了 | 查账改成完整链路：写 input.txt → main.py（写 query.txt）→ calc.exe → 读 result.txt |
| 5 | `[WARNING]` 只是原样打印 | 文档要求"红色告警 + 明细"没实现 | `parse_result()` 解析成清单 + 红色超支告警 + 剩余额度提示 |
| 6 | 追问时要退回菜单再选一次 1 | 多轮追问的体验完全断掉 | `add_expense()` 内部循环，追问时直接接着输入 |
| 7 | 预算不校验 | 输入 `abc` 直接写进 budget.txt，C 算成 0，永远"超支" | 校验必须是大于 0 的数字，并顺手显示"已花多少、剩余多少" |
| 8 | 饼图 `plt.show()` 阻塞、0 元分类标签重叠 | 容器/无显示器环境报错；饼图上叠出一堆 0% 标签 | `Agg` 后端直接存图 + 自动打开；只画金额 > 0 的分类；中文字体三级兜底 |
| 9 | `read_data()` 只认两列 | 账本改成三列后饼图直接读不出数据 | **两列三列都兼容**，饼图还会自动只统计"本月" |
| 10 | 没有最外层异常兜底 | 任何一个意外都会把界面整个崩掉 | 菜单循环内 try/except，出错只打印不退出 |

## 二、六个数据文件的最终格式（**这张表就是接口，改之前先开会**）

| 文件 | 谁写 → 谁读 | 内容格式 |
|---|---|---|
| `data/input.txt` | UI → main.py | 用户原话一行，如 `打车32` |
| `data/reply.txt` | main.py → UI | **第 1 行 `TYPE=ok/ask/query/refuse/error`，第 2 行起是正文** |
| `data/query.txt` | main.py → calc.c | 三行：`类别`（或 `ALL`）/ `开始日期` / `结束日期` |
| `data/data.txt` | main.py → calc.c | **三列** `日期,类别,金额`，如 `2026-11-22,交通,32.00` |
| `data/budget.txt` | UI → calc.c | 一个数字，如 `3000.00` |
| `data/result.txt` | calc.c → UI | `总计:520.00, 交通:30.00, 餐饮:490.00, [WARNING]` |

两个新增约定（**只有这两个是新的，其它没变**）：

1. **`reply.txt` 有 TYPE 头**：UI 靠它区分「记账成功 / 追问 / 查账 / 拒绝 / 出错」五种情况。没有头的旧格式也能读，当作 `ok`。
2. **`data.txt` 变成三列**，为了能做"上个月"这个必做功能（两列格式下时间维度根本没法做）。

`result.txt` 的解析做了容错：中英文冒号、中英文逗号、换行、`=` 都能认，所以 C 那边写法略有出入也不会显示成空白。

## 四、怎么跑

```powershell
# 1) 装依赖（只要 requests + matplotlib）
pip install -r requirements.txt

# 2) 跑起来
python ui.py

# 3) 在界面里选「5. 设置 API Key」，把 sk-xxx 粘贴进去就行
#    （会自动写进 config.txt，这个文件已经被 .gitignore 排除，不会进仓库）

# 4) 编译 C（等 calc.c 交付之后）
gcc calc.c -o calc.exe
```

**关于 API Key，三个说法**：

| 你想干什么 | 怎么做 |
|---|---|
| 正常填 Key | 运行 `python ui.py` → 选 `5` → 粘贴 → 回车（会问要不要测一下，选 y 立刻知道通不通）|
| 看现在有没有配 | 界面启动时就会提示"还没配置 API Key，现在是离线模式" |
| 确认 Key 能不能用 | `python main.py --test-api`，会打印接口、模型和模型返回的 JSON |

`config.txt` 长这样（界面会自动生成，也可以手写）：

```
api_key=sk-xxxxxxxxxxxxxxxx
base_url=https://api.deepseek.com
model=deepseek-chat
```

优先级是 **环境变量 > config.txt > 默认值**，所以临时想换个 Key 不用改文件，命令行 `$env:DEEPSEEK_API_KEY="..."` 就盖过去了。

**为什么不直接把 Key 写在 main.py 里**：考核明确写了"API Key 不进仓库，提交前检查一遍提交历史"。
写在代码里，第一次 commit 就泄露了，改回来 git 历史里还留着。放 `config.txt` 并被 `.gitignore` 排除，既好填又安全。

**没配 Key 也能跑**：main.py 会自动降级成本地规则解析（会打印一句"离线模式"），
记账、查账、追问、越界拦截全都能演示。

**灌示例数据**（答辩前快速演示饼图和超支告警）：

```powershell
copy examples\示例账本.txt data\data.txt
"500" > data\budget.txt      # 预算设 500，跑查账就能看到红色超支告警
```
